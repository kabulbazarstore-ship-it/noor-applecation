- تقویم ۱۴۰۵ و مناسبت‌های مذهبی/افغانستان در صفحه تقویم.
- اعمال امروز از حالت قفل‌شده روی یک صلوات و استغفار خارج شده و بر اساس روز و مناسبت مسیرهای واقعی دارد.
- تقویم به اعمال و مناسبت‌ها متصل است.
- اوقات شرعی کابل و شهرهای افغانستان به‌صورت محلی محاسبه می‌شود.
- نیمه‌شب شرعی و فجر فردا اضافه شده است.
- صفحه مستقل و زیباتر برای پخش اذان با دکمه SVG پخش/توقف.
- صدای پیش‌فرض اذان «موذن‌زاده اردبیلی» است و «صبح‌دل» نیز در برنامه موجود است.
- دو فایل صوتی اذان داخل بسته هستند و برای پخش دستی اینترنت لازم نیست.
- آیکن برنامه در ورود، اطلاعات برنامه و PWA از `icon.svg` و آیکن‌های محلی استفاده می‌کند.
- واتساپ از بخش لینک‌های تماس حذف شده است.
- نسخه برنامه: `۲۰۲۶ | ۱۴۰۵`.
- فونت‌ها به‌صورت محلی داخل پوشه `fonts/` قرار گرفته‌اند و وابستگی به Google Fonts / CDN حذف شده است.
- قرآن `quran.json` شامل ۱۱۴ سوره و ۶۲۳۶ آیه است و برای حالت آفلاین آماده شده است.
- Service Worker تمام فایل‌های موجود و غیرخالی برنامه، فونت‌ها و صوت‌ها را برای حالت آفلاین Cache می‌کند.
- مسیر برگشت صفحات با تاریخچه همان مبدأ هماهنگ شده تا برگشت از متن به همان بخش قبلی انجام شود.

## نصب روی GitHub Pages
1. محتویات پوشه `Noor-App` را در ریشه مخزن GitHub Pages قرار دهید.
2. GitHub Pages را روی شاخه/پوشه حاوی `index.html` فعال کنید.
3. برنامه را یک بار با اینترنت باز کنید تا Service Worker نصب و فایل‌های آفلاین Cache شوند.
4. سپس اینترنت را خاموش کنید و صفحات، قرآن و صوت‌های محلی را آزمایش کنید.

## نکته مهم درباره اذان در حالت کاملاً بسته
PWA خالص در مرورگرهای Android اجازه نمی‌دهد یک فایل MP3 دلخواه دقیقاً در ساعت مشخص، پس از بسته‌شدن کامل برنامه، به‌صورت تضمینی پخش شود. Service Worker می‌تواند اعلان نشان دهد، اما زمان‌بندی و پخش صدای واقعی در حالت کاملاً بسته توسط مرورگر تضمین نمی‌شود. برای رفتار ۱۰۰٪ شبیه برنامه‌های بومی مانند باد صبا، باید همین رابط و فایل‌ها بعداً داخل یک نسخه Android بومی با AlarmManager/Notification Channel قرار بگیرند.
